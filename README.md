基于 ADB 无线控制的 Windows 工具，OCR 自动识别芯核副词条，智能判定保留/丢弃。（**弃置率很高，请仔细看下方判定标准**）

[下载安装包](https://github.com/baijiao1213/love-deepspace-core-sorter/releases)

## 判定标准

每个副词条根据其强化次数有一个对应的**平均值**（阈值表），判定规则：

- 所有词条都 **>= 该强化次数的平均值** → 上锁保留（**非常高要求的判定，因此建议将高级或常用芯核提前上锁**）
- 任一词条 **不满足** → 弃置

> 示例：攻击加成强化了 2 次，2 次对应的平均值为 17%。如果当前值 >= 17%，该词条达标。

> **注意：** 工具仅改变芯核的锁定/弃置状态，分解仍需手动操作。

## 快速开始

1. 手机开启开发者模式 → 开启无线调试
2. 双击 `app.py` 或下载 Release 中的 exe 启动
3. 控制面板中按顺序：配对连接 → 坐标测量（首次） → 投屏（可选）
4. 游戏进入芯核页面（建议提前卸下已安在卡面上的芯核），点「开始筛选」

## 功能

- 无线 ADB 连接（无需 USB 线）
- 自动 OCR 识别副词条名称和数值
- 强化次数反推算法
- 一键保留/弃置
- 带点击验证和翻页测试的坐标测量工具
- 实时统计和 CSV 运行日志
- 免安装绿色版（Release 中下载）

## 技术栈

Python + Tkinter + PaddleOCR + OpenCV + ADB
